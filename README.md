### [Toggle Sound](https://www.nexusmods.com/warhammer40kdarktide/mods/1288)
<img width="1080" height="1080" alt="image" src="https://github.com/user-attachments/assets/d65bce07-9ea2-4a7f-9d8f-313794770a37" />

Allows you to toggle off game sounds, voice chat, or console players VC using menu toggles and keybinds. Includes hot mic detection with auto-mute and chat notifications.

**Options:**

**Sound**
- Mute Master Sound
- Toggle Master Sound (Hotkey)
- Unmute All (Hotkey)
- Include VC in Master Mute
- Mute Music
- Toggle Music (Hotkey)
- Mute Sound Effects
- Toggle Sound Effects (Hotkey)
- Show Chat Notifications

**Voice Chat**
- Mute Voice Chat
- Toggle Voice Chat (Hotkey)
- Ignore Friends
- Mute Console Players VC
- Toggle Console Players VC (Hotkey)
- Ignore Friends
- Show Chat Notifications

**Hot Mic**
- Auto-Mute Hot Mics
- Toggle Auto-Mute Hot Mics (Hotkey)
- Transmission Threshold (Seconds)
- Ignore Friends
- Show Chat Notifications
- Reset Hot Mic Mutes (Hotkey)

**Chat Commands:**
- `/mute`
- `/unmute`
- `/mute help`
